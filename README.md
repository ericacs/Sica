# Sica

A aplicação SiCA foi desenvolvida em Java utilizando sockets TCP para permitir a comunicação entre um cliente e um servidor. O servidor é iniciado primeiro e fica aguardando conexões na porta 5000. Após a conexão do cliente, o usuário pode escolher opções em um menu para listar os arquivos disponíveis, enviar arquivos para o servidor, baixar arquivos armazenados no servidor ou encerrar a aplicação.
O cliente envia comandos ao servidor, incluindo: "LISTAR", "ENVIAR", "BAIXAR" e "SAIR". Ao receber o comando "LISTAR", o servidor acessa a pasta "arquivos_servidor", verifica os arquivos existentes e envia a lista ao cliente. Caso essa pasta não exista, o próprio servidor a cria automaticamente no diretório atual da aplicação, utilizando o caminho obtido por meio de System.getProperty("user.dir").
Ao receber o comando "ENVIAR", o servidor recebe o nome, o tamanho e o conteúdo do arquivo em bytes, salvando-o na pasta "arquivos_servidor". Já no comando "BAIXAR", o servidor procura o arquivo solicitado nessa mesma pasta e, caso ele exista, envia seu conteúdo ao cliente, que salva o arquivo recebido na pasta "downloads_cliente".
O uso do protocolo sockets TCP permite uma comunicação confiável entre cliente e servidor, garantindo que os dados sejam enviados de forma ordenada e segura. Como a aplicação trabalha com transferência de arquivos, essa confiabilidade é importante para evitar perda ou corrupção dos dados durante o envio.
O código foi organizado em dois arquivos principais: "Servidor.java" e "Cliente.java". O servidor é responsável por receber e processar as requisições, gerenciar a pasta de arquivos do servidor e enviar as respostas ao cliente. O cliente, por sua vez, é responsável por interagir com o usuário, exibir o menu de opções e enviar os comandos correspondentes ao servidor. Os principais métodos foram comentados para facilitar a compreensão do funcionamento da aplicação.
